# 实验室物品借还管理系统

基于**微信小程序 + 微信云开发**的实验室物品借还管理工具。物品上贴有二维码，借还时扫码即可自动更新物品状态，所有人可随时查看物品的当前借还信息和历史记录。

## 功能特性

- **扫码借还**：物品上贴二维码，借出时扫码 → 系统标记为「已借出」；归还时再次扫码 → 标记为「空闲」。
- **实时状态**：首页展示所有物品的当前状态（空闲 / 已借出）、借用人、借出时间。
- **组织归属**：每个物品可归属到「部门 / 小组 / 人员」，由管理员/超管录入。
- **统计视图**：所有人可查看统计表，按部门 / 小组 / 人员查看物品列表，并下钻到具体物品详情。
- **历史记录**：每次借出/归还自动留痕，历史记录保存 1 年（到期由定时任务自动清理）。
- **权限分级**：
  - **普通用户**：借还物品、查看所有物品信息与历史记录。
  - **管理员**：在普通用户基础上，可随时修改任意物品的借还状态、录入新物品、删除物品。
  - **超级管理员**：在管理员基础上，可增删管理员名单。

## 快速开始

### 1. 开通云开发

1. 使用微信开发者工具打开本项目目录。
2. 在 `project.config.json` 中填入你的小程序 `appid`（云开发需要真实 appid）。
3. 点击工具栏「云开发」，开通云开发环境，记下**环境 ID**。
4. 若账号下有多个环境，在 `miniprogram/config.js` 的 `cloudEnv` 中填入环境 ID（只有一个环境可留空）。

### 2. 创建数据库集合

在云开发控制台 → 数据库中，创建以下 3 个集合（名称必须一致）：

| 集合名 | 用途 |
| ------ | ---- |
| `users` | 用户与角色 |
| `items` | 物品信息 |
| `records` | 借还历史记录 |

> 所有数据读写都通过云函数完成，云函数拥有管理端权限，无需配置客户端读写权限。

### 3. 部署云函数

在微信开发者工具中，对 `cloudfunctions/api` 和 `cloudfunctions/cleanup` 两个目录分别右键 → **上传并部署：云端安装依赖**。

- `api`：核心业务云函数。
- `cleanup`：定时清理云函数（其 `config.json` 已配置每天 03:00 触发）。

### 4. 创建数据库索引（重要）

云数据库对 `orderBy` / 范围查询需要索引。若运行时控制台提示「创建索引」，按提示点击创建即可。建议提前创建以下索引：

| 集合 | 索引字段 | 说明 |
| ---- | -------- | ---- |
| `users` | `_openid`（唯一） | 按 openid 查用户 |
| `items` | `code`（唯一） | 按编码查物品 |
| `items` | `createTime` | 物品列表排序 |
| `records` | `time`（降序） | 历史记录按时间排序 |
| `records` | `itemId` + `time`（组合） | 单个物品的历史记录 |
| `records` | `action` + `time`（组合） | 按借出/归还筛选 |

### 5. 首次初始化（超级管理员）

- 系统**第一个登录的用户会自动成为超级管理员**（这是为了让首个使用者能进入系统）。
- 之后的新用户默认是**普通用户**。
- 超级管理员可在「我的 → 管理员管理」中把用户设为/取消管理员。

> 提示：首次登录后建议到「我的」页点击「设置昵称与头像」，这样借还记录里会显示你的真实昵称，而不是默认的「微信用户」。

### 6. 录入物品并生成二维码

1. 用管理员（或超管）账号进入「我的 → 物品管理 → 新增物品」，填写物品名称、部门名、小组名、人员名等信息；物品编码留空会自动生成，也可以手动填写。
2. 记下每个物品的**编码**（如 `IL-ABC123`）。
3. 生成二维码（用于打印贴到物品上）：

   ```bash
   cd scripts
   # 复制模板并填写物品名称和编码
   cp codes.example.json codes.json   # Windows 直接复制改名即可
   npm install
   npm run gen
   ```

   生成的二维码图片在 `scripts/qrcodes/` 目录，内容就是物品编码。打印后贴在对应物品上即可。

## 使用流程

1. **借出**：打开小程序 → 首页点「扫码借还」→ 扫描物品二维码 → 确认借出。
2. **归还**：再次扫描该物品二维码 → 确认归还。
3. **查看**：首页看所有物品状态；「统计」页按部门/小组/人员查看物品列表；「历史」页看全部借还记录；进入物品详情看单个物品的历史。
4. **管理**：管理员在「物品管理」中可新增/编辑/删除物品，或「标记借出/标记归还」强制修改状态（用于线下借还、代他人操作等场景）。

## 数据模型

```js
users:   { _openid, nickname, avatarUrl, role: 'user'|'admin'|'superadmin', createTime }
items:   { code, name, description, department, groupName, ownerName,
           status: 'available'|'borrowed', borrowerOpenid, borrowerName, borrowTime,
           createTime, updateTime }
records: { itemId, itemCode, itemName, openid, userName, action: 'borrow'|'return',
           time, operatorOpenid, operatorName }
```

## 常见问题

- **扫码后提示「未找到该物品」**：二维码内容与物品编码不一致，或物品尚未录入。请确认二维码内容等于物品的 `code`。
- **借还按钮不可见 / 提示无权限**：角色不对。管理员按钮只在 `admin` / `superadmin` 角色下显示。
- **运行时报「索引不存在」**：到云开发控制台按提示创建索引（见上文索引表）。
- **只有一个人能借还自己以外的物品**：普通用户只能归还自己借的物品；管理员可「代归还」，或使用「标记借出/标记归还」强制改状态。
